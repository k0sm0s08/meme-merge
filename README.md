# Мелстрой мерж

HTML5 Suika-пазл: одинаковые круглые мемы сливаются, растут и приносят очки. Phaser 3.90, встроенный Matter.js, строгий TypeScript и Vite. Фоновая музыка и отдельные настройки звука. Без рекламы, Яндекс SDK, React, собственного сервера и внешних CDN.

## Запуск

Нужен Node.js 22.12 или новее (в подготовленной облачной среде — Node.js 24).

```bash
cd /workspace/meme-merge
npm ci --cache /workspace/.cache/npm
npm run dev -- --port 5173 --strictPort
```

В обычной локальной среде достаточно `npm ci` и `npm run dev`. Команда выводит адрес сервера. Для просмотра собранной игры: `npm run build`, затем `npm run preview`.

Для подготовки новых локальных исходников: `npm run prepare:memes -- /путь/к/папке/исходников`. Утилита сохраняет оригиналы, создаёт компактные прозрачные PNG 512 × 512 в `public/assets/memes/` и требует установленный Chromium. Используй её только при намеренной замене изображений, а не как шаг установки среды.

```bash
npm run typecheck
npm run build
npm run check:build
npm test
npm run test:production
```

Браузерные проверки используют локальный Chromium (`/usr/bin/chromium`); другой путь можно задать через `CHROMIUM_PATH`. Установка браузера не входит в зависимости игры. `npm test` сам запускает тестовый Vite на порту 4174 и останавливает его; production-проверка требует готовую папку `dist/`. Скриншоты и отчёты сохраняются в игнорируемой папке `test-results/`. Тестовые инструменты доступны только в dev-режиме с `VITE_TEST_MODE=1` и отсутствуют в production.

## Управление и правила

- Мышь: двигай прицел по полю, кликай левой кнопкой для сброса.
- Телефон: коснись поля, двигай палец, отпусти для сброса. Палец захватывается указателем: движение и отпускание за пределами поля продолжают управлять мемом. Отмена касания, потеря захвата или пауза отменяют жест без сброса. Второй палец не создаёт дополнительный мем.
- После сброса действует задержка 420 мс. Предпросмотр справа показывает следующий мем.
- При слиянии начисляются очки **полученного уровня**: 1 + 1 → 2 даёт 4 очка; 2 + 2 → 3 даёт 8. Комбо показывает длину быстрой цепочки, не умножает табличные очки.
- В игре 10 мемов. Цепочка по номерам картинок: `01 → 02 → 03 → 04 → 05 → 07 → 08 → 09 → 10 → 11`. Два мема 05 сразу создают мем 07 и дают 128 очков. Уровень 06 полностью исключён; все игровые диаметры и коллайдеры увеличены в 1,12 раза, награды сохранены.
- Два мема уровня 11 исчезают и дают 2048 очков; партия продолжается.
- После 1,5 с на стабилизацию спокойный мем, остающийся выше пунктирной линии 2 с, завершает партию. Если опасность исчезает, его таймер сбрасывается.
- Кнопка паузы и Escape останавливают физику и эффекты. Потеря фокуса или скрытие вкладки автоматически ставят игру на паузу; возврат не возобновляет её без действия игрока.
- Начало заново и выход в меню во время партии требуют подтверждения.
- Рекорд, число начатых партий и максимальный уровень сохраняются в `localStorage` (`meme-merge.save.v1`). Если хранилище недоступно, игра использует память и продолжает работать.
- Старые сохранения с максимальным уровнем 06 переводятся на 07. Рекорд и число партий не сбрасываются.

## Изображения

Используются все 10 фотографий из архива пользователя: 01–05 и 07–11. Зелёный фон и поля скриншотов удалены, края вырезок мягкие и прозрачные. Отсутствующий уровень 06 удалён из игры по запросу пользователя. Временного мема 06 больше нет, файл для него не требуется. Порядок остальных изображений сохранён. Неизменённый оригинальный ZIP находится в `artwork/source/` и не попадает в сборку игры.

Активные изображения находятся в `public/assets/memes/`: `meme-01.png`–`meme-05.png` и `meme-07.png`–`meme-11.png`. Номера файлов сохранены. Цепочка определяется порядком записей `LEVELS` в `src/config/gameConfig.ts`, а не прибавлением единицы к номеру. Подготовка и загрузка ресурсов используют только активные уровни, поэтому файл 06 не включается в игру даже при наличии в исходниках. **Перезапусти Vite или пересобери проект после замены изображений.**

Изображения загружаются один раз. Canvas 2D сохраняет пропорции, прозрачность и мягкий контур персонажа с деликатной подсветкой. Для локальных скриншотов на зелёном фоне предусмотрена подготовка при загрузке: chroma key, удаление зелёной каймы, обрезка телефонных панелей и прозрачных полей. Оригиналы не изменяются. Готовые текстуры кэшируются и используются как в игре, так и в интерфейсе. У фотографий нет непрозрачного цветного диска: физическая оболочка остаётся круглой и невидимой, край рисунка мягко ограничивается ею. Отсутствующие или не загрузившиеся файлы заменяются только для своего уровня временными мемами.

## Звук и оформление

Название в меню, интерфейсе, результатах и метаданных — «Мелстрой мерж». Адрес GitHub Pages и имя репозитория остаются `meme-merge`.

`BALL_SIZE_MULTIPLIER = 1.12` увеличивает все десять игровых диаметров и коллайдеров. Контейнер, очки, веса выпадения, цепочка (включая 05 → 07), настройки Matter и таймер переполнения не меняются. Иконки и фотографии в интерфейсе сохраняют свои размеры.

Две локальные фотографии из `public/assets/backgrounds/` отображаются по бокам на экранах шире 1090 px. Пропорции сохранены; изображения полупрозрачны, имеют мягкую маску и не принимают клики. На узких экранах они скрыты.

Один `AudioManager` живёт всё время работы приложения. `video-audio-02.mp3` — зацикленная музыка с громкостью 0,22, которая начинается после доверенного взаимодействия пользователя. Отдельные переключатели «Музыка» и «Звуки» находятся в меню, на паузе и в настройках звука во время игры. Их состояние хранится в `meme-merge.audio.v1`, отдельно от старых рекордов. Музыка при перезапуске не создаётся заново. Пауза, скрытие вкладки, потеря фокуса и будущая рекламная пауза останавливают звук; игровая пауза сохраняется до нажатия «Продолжить».

`video-audio-01.mp3` и `video-audio-03.mp3` подключены как доступные ресурсы для `playEffect`, но пока не назначены на игровые события. Одновременно разрешён только один длинный клип; на время его явного воспроизведения музыка приостанавливается. Реклама и SDK не добавлены. Неизменённый исходный архив с фотографиями и аудио хранится в `artwork/source/mellstroy-merge-assets.zip` и не входит в сборку сайта.

## Структура

```text
public/assets/memes/        10 прозрачных изображений (без 06)
public/assets/backgrounds/ две декоративные фотографии
public/assets/audio/        три локальных MP3
public/assets/ui/           локальная иконка
src/config/gameConfig.ts   уровни, размеры, очки, вероятности, физика, таймеры
src/scenes/BootScene.ts    загрузка и подготовка текстур
src/scenes/MenuScene.ts    главное меню
src/scenes/GameScene.ts    партия, управление, пауза и жизненный цикл
src/game/AimController.ts  захват указателя и координаты вне поля
src/game/BallManager.ts    тела, визуальное отображение и очистка
src/game/MergeManager.ts   блокировки пар и отложенные слияния
src/game/OverflowMonitor.ts условие проигрыша
src/game/ScoreManager.ts   очки и комбо
src/services/AudioManager.ts музыка, звуки и сохранённые настройки
src/services/SaveService.ts безопасное сохранение
src/services/PlatformService.ts граница будущей интеграции SDK
src/ui/                   DOM-интерфейс, подготовка вырезок, текстуры, эффекты
tests/                    браузерные сценарии
```

Физика использует фиксированный шаг 1/120 с, ограниченное число шагов за кадр, предел линейной и угловой скорости и интерполяцию отрисовки. Отскок и вращение приглушены, прицел плавно следует за пальцем или мышью; сброс происходит точно в точке отпускания/клика. Удаление и создание тел происходят после завершения шага Matter, пары блокируются сразу при контакте. Новый мем сохраняет часть импульса и получает небольшую коррекцию позиции, уменьшающую наложение на соседей. Проверяются начавшиеся и продолжающиеся столкновения для цепных слияний. Физический мир всегда 390 × 844 и не меняется с размером окна; Phaser Scale Manager масштабирует Canvas, DOM-интерфейс повторяет его масштаб. На компактных экранах области кнопок увеличиваются до 44 экранных пикселей. Учтены safe area и reduced motion.

## Публикация в браузере

Инструкция с кнопками GitHub и бесплатной альтернативой для приватного репозитория находится в [docs/PUBLISHING.md](docs/PUBLISHING.md).

По умолчанию Vite собирает игру с `base: '/meme-merge/'` для GitHub Pages. Workflow `.github/workflows/deploy-pages.yml` проверяет сборку в Pull Request, а после обновления `main` публикует содержимое `dist/`. Первый раз нужно выбрать **Settings → Pages → Source → GitHub Actions**. Из Pull Request публикация не выполняется.

`npm run check:build` проверяет ссылки JS/CSS/иконки в HTML и соответствие 10 PNG, двух WebP и трёх MP3 исходным файлам. `npm run test:production` запускает готовую сборку по пути `/meme-merge/`, проверяет загрузку всех мемов, фотографий и аудиофайлов, слияния и отображение на телефонном и компьютерном размерах.

Локальный `npm run dev` использует корневой путь `/`, поэтому команды разработки остаются прежними. Для хостинга в корне домена, например Cloudflare Pages, установи `VITE_BASE_PATH=/` перед сборкой. Для относительных путей, необходимых при отдельной подготовке к Яндекс Играм, используй `VITE_BASE_PATH=./ npm run build`.

## Статическая сборка

`npm run build` создаёт `dist/index.html` и локальные ресурсы по настроенному base path. GitHub Pages и Cloudflare Pages открывают эту сборку по обычной HTTPS-ссылке на компьютере и телефоне. Скачивание архивов для тестирования не требуется. Подготовка отдельной сборки для Яндекс Игр выполняется отдельно.

`PlatformService` — интерфейс для событий ready/gameplay, rewarded, interstitial и отправки счёта. Текущий локальный адаптер не вызывает SDK и всегда возвращает `false` для награды. В `GameScene` подготовлены методы бомбы и второго шанса: эффект применяется только после подтверждённой награды. Второй шанс ограничен одним на партию. Рекламных кнопок в интерфейсе нет.

## Что проверить вручную

- Удобство управления, баланс и скорость физики в длинных партиях на настоящих Android и iPhone (включая Safari).
- Поворот экрана, вырезы и панели браузера; повторное касание и несколько пальцев.
- Частоту кадров и потребление памяти на слабых устройствах. Цель — около 60 FPS, но без замеров на устройствах это не гарантия.
- Кадрирование и различимость всех 10 фотографий на маленьких экранах.
