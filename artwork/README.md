# Исходные мемы

`source/meme-merge-images.zip` — неизменённый архив пользователя. В нём 10 изображений с номерами 01–05, 07–11. По запросу пользователя шестой уровень исключён из игры: слияние двух мемов 05 создаёт мем 07. Файл `meme-06.png` не требуется. Существующие изображения не перенумеровываются.

Архив находится вне `public/` и не входит в production-сборку. У большинства исходников расширение `.png`, но фактически они JPEG; игровой браузер определяет формат по содержимому. Для игры подготовлены настоящие прозрачные PNG в `public/assets/memes/`, с сохранением исходной нумерации.

Подготовка: удаление зелёного фона и телефонных панелей, небольшой прозрачный отступ, мягкий альфа-контур. В игре сохранена круглая невидимая физическая оболочка для предсказуемых контактов; поверх неё отображается вырезанный персонаж без цветного диска.

## Дополнительные фотографии и аудио

`source/mellstroy-merge-assets.zip` — неизменённый новый архив пользователя: две WebP-фотографии и три MP3. Файлы скопированы без перекодирования в `public/assets/backgrounds/` и `public/assets/audio/`. Исходные фотографии уже компактны (83 и 97 КБ), музыка MP3 44,1 кГц занимает 1,7 МБ; дополнительное сжатие не требуется. Мягкие края фотографий реализованы CSS-маской, оригиналы не изменяются.
