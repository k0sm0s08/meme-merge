# Загрузка «Мелстрой мерж» в Яндекс Игры

Код, SDK, второй шанс и материалы подготовлены. Ниже — действия в двух сайтах. Пароли, токены и доступ к кабинету в код добавлять не нужно.

## 1. Скачать готовую игру с GitHub

1. Открой Pull Request обновления в репозитории https://github.com/k0sm0s08/meme-merge. Дождись зелёной проверки **Prepare Yandex Games upload**.
2. Нажми **Merge pull request → Confirm merge**. Это обновит `main` и запустит обычную публикацию GitHub Pages и отдельную подготовку игры для Яндекса.
3. Открой **Actions → Prepare Yandex Games upload**. Выбери последний успешный запуск для `main` (зелёная галочка).
4. Внизу страницы, в **Artifacts**, нажми **yandex-games-upload**. Скачается ZIP **из GitHub**, а не артефакт из чата. Сохрани его и **не распаковывай для загрузки**. Внутри сразу лежат `index.html` и `assets/`, без лишней папки `dist-yandex`.
5. Там же скачай **yandex-card-materials** и распакуй этот второй архив: из него нужны отдельные картинки и текст `listing.txt`.

Можно тестировать сборку до слияния: артефакты доступны и в успешном запуске проверки PR. Для ручной пересборки после слияния: **Actions → Prepare Yandex Games upload → Run workflow → main → Run workflow**. Артефакты хранятся 30 дней; после истечения запусти workflow ещё раз. Для скачивания войди в свой аккаунт GitHub.

GitHub Pages продолжает использовать `dist/` и `/meme-merge/`. Его служебный артефакт `github-pages` для Яндекса не подходит. Скачивать архив из ответа ChatGPT не требуется.

## 2. Создать черновик Яндекс Игр

1. Открой https://games.yandex.ru/console/developer и войди в свой аккаунт Яндекса. Если кабинет предложит регистрацию разработчика или договор, заполни их от своего имени.
2. Нажми **Добавить игру**. Создай новый черновик.
3. В поле **Архив** загрузи скачанный `yandex-games-upload.zip`.
4. Выбери **русский язык**, **компьютеры и мобильные устройства**, **портретную ориентацию**. Авторизация, покупки и таблицы лидеров этой игре не нужны. Дополнительные внешние хосты для игровых ресурсов не используются.
5. В блоках описания скопируй название, короткое описание, «Об игре» и управление из `listing.txt`.
6. Загрузи `icon-512.png` как иконку, `cover-800x470.png` как обложку и файлы `screenshot-*.png` как скриншоты. Подготовленные размеры указаны в именах. Если интерфейс кабинета предъявляет другие текущие требования, руководствуйся ими.
7. Выбери подходящие категории, теги и возрастной рейтинг по содержимому игры. Фото и аудио предоставлены пользователем; лицензии и согласия в проект не вложены. Перед модерацией нужно подтвердить права на эти материалы, включая фотографии людей и музыку. Это нельзя выполнить изменением кода.
8. Сохрани черновик и открой его тестовый запуск/ссылку в кабинете. Это место для проверки настоящей рекламы. Отправь эту ссылку на свой телефон для второго теста.

Названия элементов кабинета могут меняться. Официальные инструкции: [добавление игры](https://yandex.ru/dev/games/doc/ru/console/add-new-game), [требования](https://yandex.ru/dev/games/doc/ru/concepts/requirements), [SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about), [реклама](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv). Прямое чтение этих страниц в текущей облачной среде заблокировано сетевой политикой; соответствие последним правилам и решения модерации не подтверждено.

## 3. Проверить перед модерацией

- На компьютере и телефоне мемы показываются без зелёного фона; прицел, падение и слияния работают. 05 + 05 создаёт 07; уровня 06 нет.
- Музыка начинается только после касания/клика. Пауза, реклама, скрытие вкладки и переключение окна останавливают звук и игру. Возвращение во вкладку показывает паузу.
- После проигрыша нажми **Второй шанс · за рекламу**. До завершения рекламы поле и счёт не меняются. При подтверждённой награде верхняя часть поля очищается, счёт и текущая партия сохраняются. При повторном проигрыше второго шанса больше нет; новая партия снова его допускает.
- Ошибка/отсутствие рекламного объявления позволяет попробовать ещё раз или начать новую партию. Объявления могут отсутствовать в черновике: отсутствие показа не означает выдачу награды. Готовая обычная версия на GitHub Pages не показывает эту кнопку и не подменяет рекламу таймером.
- Проверь поворот телефона, долгое удержание пальца, выход из вкладки во время рекламы и возвращение. Пройди длинную партию на своём телефоне; эмуляция Chromium не заменяет Android/iPhone.
- Перезагрузка сохраняет рекорд, максимальный уровень и настройки звука в этом браузере. Текущая расстановка мемов между перезагрузками и перенос рекорда между устройствами не реализованы. Аккаунт Яндекса для игры не запрашивается.

После успешного теста нажми в кабинете **Отправить на модерацию**. Если игра одобрена, опубликуй её через предложенную кабинетом кнопку и используй полученную ссылку. Сроки и результат модерации определяет Яндекс. Я не создавал черновик и не отправлял игру от твоего имени.

## Для разработки

```bash
npm ci
npm run build:yandex
npm run check:yandex
npm run test:yandex
```

Сборка в `dist-yandex/` с `base: './'`, меньше 100 МБ до сжатия. Только этот режим загружает `/sdk.js`, который предоставляется хостингом Яндекс Игр. Внешних игровых ассетов или скопированной версии SDK в архиве нет. Без SDK игра остаётся доступной, а награда не выдаётся.

`LoadingAPI.ready()` вызывается после подготовки текстур и меню. `GameplayAPI.start/stop()` отражают партию и паузы. События `game_api_pause/resume` поддержаны; возврат не снимает пользовательскую паузу. Rewarded video вызывается исключительно по нажатию кнопки игроком, без фоновых или межстраничных объявлений.

Браузерные тесты используют подстановку SDK только на уровне маршрута Playwright. Она не входит в исходники приложения или релиз. Проверены закрытие без награды, ошибки и исключения, повторные callbacks, ожидание закрытия после награды, пауза SDK, сохранение партии, ограничение второго шанса и callback из старой сцены. Сама реклама и связь с настоящим SDK должны быть проверены в черновике Яндекса.

Материалы карточки хранятся в `publishing/yandex/`. Для пересъёмки реального интерфейса: `npm run build`, затем `node scripts/capture-yandex-materials.mjs`. Требуется Chromium; скрипт не изменяет игровые фото или механику.
