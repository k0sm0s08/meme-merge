# Исправить контурные хитбоксы и экран коллекции в «Мелстрой мерж»

Фотографии были прозрачными силуэтами внутри круглых коллайдеров. Например, мем 01 имел видимую ширину 20,74 при физическом диаметре 33,60, а мем 10 — высоту 111,56 при диаметре 168. Поэтому столкновения и слияния происходили через пустые участки рисунка. Коэффициент ×1.12 применялся корректно; ошибка заключалась в форме тела.

По выбору пользователя сохранены силуэты. Из текстур убраны лишний отступ, повторное размытие, круговая маска и тень. PNG-оригиналы не изменены. Alpha-контуры и выпуклые части кэшируются при загрузке; тела и спрайты используют один центр массы. Номинальные размеры ×1.12 сохранены. Контакты частей сопоставляются родителю, слияния не дублируются и удаляют целые тела. При слиянии спрайт больше не увеличивается сверх коллайдера; новые тела позиционируются по настоящим частям соседей. Границы прицела и условие переполнения учитывают реальные силуэты.

Для быстрых движений шаг 1/120 с делится на два полушага 1/240 с. Это исправляет обнаруженное зацепление тонких частей без постоянного удорожания спокойной кучи. Упругость, трение, плотность, итерации 10/8, ограничения скоростей и таймеры сохранены. Очки, вероятности и переход 05 + 05 → 07 не изменены.

Удалена кнопка «Как играть» и неиспользуемый код инструкции; встроенные подсказки сохранены. Коллекция и другие модальные окна скрывают основную DOM-секцию и canvas через состояние, затем корректно восстанавливают их. Переработка z-index не используется как замена этому исправлению. Добавлен режим `?debugPhysics=1` с контурами тел, центрами и стенками; по умолчанию выключен.

## Проверки

- `npm test`: 54 успешные проверки Chromium, включая 10 альфа-контуров, повороты, пол, стены, смешанную и плотную кучу, 45 объектов, слияния и все уровни, сенсорное управление, аудио и сохранения.
- Совпадение видимого силуэта и объединения частей >99%; максимальная ошибка края 1,75 игрового пикселя. Зазор у пола <0,32 пикселя. В проверенной смешанной куче проникновение <0,1 пикселя.
- Повторные открытия коллекции, её вид на телефоне/ПК и изменение размера окна при открытом окне проверены. Сделаны скриншоты с физической отладкой и без неё.
- Чистый `npm ci`, `npm run build` (TypeScript), `npm run check:build`, `npm run test:production` успешны. Production проверен по `/meme-merge/`, загружены все 15 ресурсов, dev API и внешних запросов нет.
- Проверки выполнены в Chromium с эмуляцией сенсорного ввода; физические Android/iPhone и Safari требуют ручной проверки.
