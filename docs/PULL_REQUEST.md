# Обновить «Мелстрой мерж»: управление, размеры, оформление и музыка

На телефоне отпускание пальца вне поля отменяло сброс и фигурка переставала следовать за жестом. Теперь активное касание захватывается через Pointer Events, продолжает управлять прицелом за пределами поля и canvas и сбрасывает ровно один мем при отпускании. Отмена, потеря захвата и пауза безопасно прекращают жест. Мышь сохраняет прежнее управление кликом, кнопки не запускают сброс, второй палец игнорируется.

Все десять игровых диаметров и физических коллайдеров увеличены на 12% через `BALL_SIZE_MULTIPLIER = 1.12`. Контейнер, очки, вероятности, цепочка 01–05 → 07–11, параметры Matter, таймер проигрыша и старые сохранения не меняются.

Название изменено на «Мелстрой мерж». Палитра стала спокойнее; две фотографии из приложенного архива мягко вписаны по бокам на широких экранах и скрыты на узких. Интерфейс сохраняет центральное поле и прежние экраны, с отдельными переключателями музыки и звуков.

Один AudioManager воспроизводит `video-audio-02.mp3` циклически после доверенного жеста пользователя, с громкостью 0,22. Настройки хранятся отдельно от рекордов. Пауза, фокус, видимость и будущая рекламная пауза останавливают аудио; перезапуски не создают новых копий. Клипам 01 и 03 не назначены автоматические игровые события; одновременное воспроизведение длинных клипов исключено. Реклама и SDK не добавлены.

Новые WebP/MP3 сохранены без перекодирования, оригинальный архив сохранён в artwork/source. Адрес GitHub Pages и workflow публикации остаются прежними, новые ресурсы используют Vite BASE_URL.

## Проверки

- `npm run build`: TypeScript и production-сборка.
- `npm run check:build`: base `/meme-merge/`, JS/CSS/favicon, 10 PNG, 2 WebP и 3 MP3.
- `npm test`: 43 проверки Chromium, включая реальные столкновения, все размеры и переходы уровней, таймер проигрыша, сохранения, аудио и Pointer Events через сенсорный ввод CDP.
- Проверены выход пальца за пределы поля и canvas, отпускание снаружи, `pointercancel`, реальная потеря захвата, второй палец, кнопки и пауза во время жеста.
- Проверены размеры экранов 320×568, 390×844, 768×1024, 1920×1080 и 844×390; фотографии не перекрывают поле, горизонтальной прокрутки нет.
- `npm run test:production`: собранная игра по `/meme-merge/`, все 15 ресурсов, слияния, пауза, мобильный и компьютерный размеры, без внешних запросов и dev API.

Проверки выполнены в Chromium с эмуляцией сенсорного ввода и размеров экрана. Проверка на физических Android/iPhone и Safari остаётся ручной.
