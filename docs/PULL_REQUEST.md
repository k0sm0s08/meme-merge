# Добавить Мемный Мерж и публикацию через GitHub Pages

В `main` сейчас находится только начальный README. Изменение добавляет готовую игру и автоматическую публикацию, чтобы её можно было тестировать по HTTPS-ссылке на компьютере и телефоне без скачивания архивов.

Игра использует Phaser 3, Matter.js, TypeScript и Vite. В ней 10 обработанных фотографий, цепочка `01 → 02 → 03 → 04 → 05 → 07 → 08 → 09 → 10 → 11`, пауза, рестарт и сохранение рекорда. Настройка публикации не меняет механику, физику или интерфейс.

Vite использует `/meme-merge/` для GitHub Pages. GitHub Actions проверяет PR и публикует `dist/` после обновления `main`. Для Cloudflare Pages поддержан `VITE_BASE_PATH=/`. Инструкция с кнопками находится в `docs/PUBLISHING.md`.

Проверки:

- `npm run build`: строгий TypeScript и production-сборка.
- `npm run check:build`: пути JS/CSS/иконки и целостность всех 10 PNG.
- `npm run test:production`: реальная загрузка всех 10 мемов по `/meme-merge/`, слияния, пауза, телефонный и desktop-размеры; без внешних запросов и тестового API.
- `npm test`: существующие 30 браузерных сценариев, включая переход 05 → 07 и перенос старых сохранений.

Для первой публикации владелец выбирает **Settings → Pages → Source → GitHub Actions**. До успешного задания `deploy` ссылка на Pages не считается опубликованной.
