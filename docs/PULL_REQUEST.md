# Add Yandex Games rewarded second chance and upload build

Мемы теперь показываются из кэшированных текстур 512×512 вместо 256×256. Проверенные маски силуэтов 256×256 готовятся отдельно из тех же PNG: формы тел, размеры, физические параметры и переход 05→07 сохраняются.

Отдельный режим `yandex` создаёт `dist-yandex/` с относительными путями и подключает SDK хостинга `/sdk.js`. Передаются LoadingAPI/GameplayAPI и поддерживаются паузы платформы. На экране проигрыша добавлен добровольный второй шанс: `onRewarded` с последующим `onClose` очищают верх поля и продолжают ту же партию с тем же счётом. Награда допускается один раз на партию. Ошибки, закрытие без награды, повторные нажатия/callbacks и callbacks из старой сцены не дают лишнего продолжения. Игра и звук приостановлены во время рекламы; скрытая вкладка остаётся на паузе.

GitHub Pages сохраняет прежнюю отдельную сборку и не загружает SDK. Новый workflow **Prepare Yandex Games upload** проверяет обе версии и создаёт скачиваемые в GitHub Actions архивы игры и материалов карточки. Добавлены иконка, обложка, три реальных скриншота, русский текст карточки и простая инструкция `docs/YANDEX_GAMES.md`.

Проверено локально в Chromium:

- `npm run build` и `npm run check:build`.
- `npm run build:yandex` и `npm run check:yandex`: 22 файла, 6,07 МБ до сжатия, index.html в корне, локальные ресурсы и относительные пути.
- `npm test`: 43 сценария игры и 11 сценариев физики.
- `npm run test:production`: реальные слияния и ресурсы по /meme-merge/, без внешних запросов и тестового API.
- `npm run test:yandex`: 10 сценариев SDK, наград, пауз, ошибок, перезапуска и загрузки production по вложенному URL.

Подстановка SDK существует только в тестовом маршруте Playwright. Реальный SDK, показ рекламы, Android/iPhone и модерация требуют проверки в черновике Яндекс Игр. Права на предоставленные фотографии и музыку, возрастной рейтинг и действия в кабинете разработчика выполняет владелец.
